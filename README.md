# NEXUS — команда ИИ-агентов

Локальная система управления командой ИИ-агентов: пульт-чат, конструктор,
программы ПК, MCP-серверы, Telegram-пульт, RAG-базы знаний и vision-вложения.
Без зависимостей — только встроенные модули Node.js.

```bash
cd nexus
node server.js
# → http://localhost:3100
```

Подробная документация — в [nexus/README.md](nexus/README.md).

## Безопасность перед публикацией

Папка `nexus/data/` (ключи, PIN, переписка, журнал) исключена из git
через `.gitignore` и создаётся заново при первом запуске.
